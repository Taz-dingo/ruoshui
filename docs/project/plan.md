# 项目 Plan

最后更新：`2026-07-04`

## 已完成基础

- 已验收高质量 `SOG` 场景，并以 `assets/hhuc.sog` 作为仓库唯一正式源。
- 已完成 React/Vite/PlayCanvas viewer、镜头、小地图、热点、加载与性能基础。
- 已上线 `Cloudflare Pages`，重模型经 `R2 + Pages Functions` 同源提供。
- 已建立 `Workers + D1 + R2` 社区服务和最小帖子/点位/媒体 contract。
- 已走通“场景点位 → 点位笔记 → 完整社区 → 详情 → 返回场景”的本地业务闭环。
- 训练与算法实验历史已归档到 [`../archive/model-training/`](../archive/model-training/)。

## 阶段 A：Viewer 收口

- 复验 Mobile Safari 视口与手势。
- 继续压低首屏加载和静止运行成本。
- 保持生产构建只发布前端壳，重量级模型走同源代理。

## 阶段 B：场景内容生产

- 确定首批正式点位、坐标、封面和正文。
- 建立点位校准与内容验收流程。
- 避免页面启动时自动写入生产数据；种子内容走显式脚本或管理流程。

## 阶段 C：社区闭环

- 收口社区 feed、详情、发布与多图体验。
- 做实点位筛选和帖子双向关联。
- 补加载、空态、错误态和并发请求保护。

## 阶段 D：Cloudflare 生产化

- 为 D1 列表/详情补分页、索引复核与迁移纪律。
- 为 R2 补上传确认、校验、孤儿对象清理和公开 URL 策略。
- 固化部署、回滚和线上健康检查。

## 延后能力

- 登录、权限、审核和开放 UGC。
- 完整内容后台与复杂互动系统。
- 新一轮模型训练、算法切换或自研 renderer。

只有当前业务目标明确要求时才重启这些方向。
