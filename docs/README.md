# 文档索引

## 默认入口

正常恢复项目时，只需要先读这两份：

- [`project/state.md`](project/state.md)：最新实现状态与恢复入口。
- [`project/tasks.md`](project/tasks.md)：当前优先级与下一步。

按需再扩展：

- [`project/spec.md`](project/spec.md)：产品边界不清楚时再读。
- [`project/plan.md`](project/plan.md)：需要看阶段路线时再读。
- [`project/engineering-memory.md`](project/engineering-memory.md)：deploy / debug / 验证链路时再读。
