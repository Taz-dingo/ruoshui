# Security

## Reporting

Please do not report security-sensitive problems in a public issue or pull request.

Use GitHub private vulnerability reporting when the repository shows a **Report a vulnerability** action. If that option is unavailable, contact the maintainer through a private channel listed on the maintainer's GitHub profile.

Share only the minimum information needed to reproduce the problem, and avoid posting private production data in public discussions.

## Supported version

Security fixes target the current `main` branch and the current production deployment.
